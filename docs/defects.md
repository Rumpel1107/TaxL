# Defects — TaxL

> **What goes in this document:** everything that broke after it was called done — in the
> engine, in a rule sheet, or in a figure already used somewhere. Found by a golden test that
> had been passing, by a review, by a professional, or by a real case. Work still being built
> stays out: a number that is wrong before the sheet is finished is the work, not a defect.
>
> Not here: what is pending (`docs/roadmap.md`), why something was settled (`docs/decisions.md`),
> what happened (`docs/log.md`), or what a defect taught beyond this project (`lessons.md` in
> the `/method` skill).
>
> Append-only. A defect that comes back is a **new row** naming the earlier one in Cause, never
> an edit of the old row: the pair is the signal.
>
> Ids are `DEF-1`, `DEF-2`, … — never a bare `D1`, which is a decision in `docs/decisions.md`.
